# ROADMAP · 未来改进方向

> 产品愿景：**只需要 PDF 教材和题库，依托 AI，帮助普通人完全且快速地学会一门知识、通过一门考试。**

当前已覆盖的学习闭环：

```
📕 PDF/MD 教材导入 → AI 笔记化 → ✨ AI 出题 → 📝 练习+批改 → 📇 错题/好题归档
   → 📐 模板归纳 → 🧠 间隔重复复习 → 🎯 模拟考试 → 📊 掌握度仪表盘
```

## 近期（P0，最接近愿景缺口）

1. **扫描版 PDF OCR**：pdf.js 只能提取文字层；接入 OCR（PaddleOCR / Tesseract.wasm 或云 OCR）后，拍照/扫描教材也能导入。
2. **学习计划生成**：输入考试日期 + 每日可用时长，AI 依据题库章节分布与考点掌握度生成每日学习计划，并在仪表盘执行追踪（今日该学什么、该复习什么）。
3. **掌握度驱动的练习推荐**：仪表盘已统计考点正确率——下一步让「练习」支持「弱项优先」自动出题（按考点聚合错题 + 未练过的题）。
4. **考试大纲结构对齐**：支持导入考试大纲（章节-题型-分值分布），模拟考试按大纲组卷，出分后与历史通过线对比。

## 中期（P1，体验与规模）

5. **批量 AI 解析**：模拟考主观题已有逐题「AI 解析」，增加"一键全部解析"与 token 成本预估。
6. **对话式讲解**：批改报告 / 圈选提问 / 右键提问升级为可追问的多轮对话 tutor，自动携带上下文。
7. **卡片多媒体**：复习卡片支持图片与公式编辑器；TTS 朗读辅助记忆。
8. **FSRS 调度**：SM-2 简化版升级为 FSRS 算法，复习安排更精准。
9. **存储升级**：db.json 全量读写改造为 SQLite（仍零配置、单文件），支撑整本教材 3000+ 题规模。
10. **移动端 PWA**：manifest + service worker，手机安装，碎片时间刷卡复习。

## 远期（P2，生态）

11. **OCR 管线内置化**：「PDF→图片→OCR→结构化 md」内置流水线（本地 wasm 或可选云端），实现"丢进任何 PDF 都能学"。
12. **同步与多设备**：可选 WebDAV / S3 同步或轻量账号体系。
13. **题目质量自检**：AI 出题后自动交叉验证（答案唯一性、干扰项质量、考点覆盖率），低质题自动重写。
14. **学习报告**：周报——投入时长、掌握度变化曲线、考试分数区间预测。

## 设计原则（延续）

- **本地优先**：数据始终在本地文件，AI 经本地服务器代理，密钥不出本机
- **AI 可调**：全部提示词可视化编辑，判定/裁决类输出结构化可解析
- **人工兜底**：相似度裁决、批改结论均可人工覆写，AI 只辅助不替你做主
- **体验优先**：允许引入必要的本地依赖，功能强大与简单易用并存
